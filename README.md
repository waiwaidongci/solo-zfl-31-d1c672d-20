# 手工织锦纹样排版台 · 版权台账

直接用浏览器打开 `index.html` 使用，无需构建、无外部依赖。

## 纹样编辑（原有能力）

- 自定义经纬网格，点击/拖动填色，支持单点、十字、小菱形纹样块。
- 色线用量统计、重复单元预览、断线（换色过密）风险提示。
- 撤销 / 重做（最多 50 步）。
- 一键本地保存；导出 / 导入 JSON 文件。

## 版权登记与授权台账（新增）

### 版权登记
- 以**当前纹样指纹**（由网格尺寸与全部填色确定性计算，10 位大写编码）建立唯一登记号 `ZB年-指纹-序号`。
- 登记权利人、创作日期、系列、版权状态（正常 / 权属争议 / 已终止）。
- **同一指纹只能登记一次**；登记同时保存该纹样快照，指纹与快照不一致的导入文件会被拒绝。
- 非「正常」状态的登记不能对外签发许可。

### 授权签发
- 授权专员登记：被授权方、用途、地域、渠道、授权类型（普通 / 排他）、起止日期。
- **排他授权**不得与同登记、同用途 + 地域 + 渠道、日期重叠的其它有效许可共存（无论对方是普通还是排他）。
- **相同范围**（同登记、同用途/地域/渠道）、相同被授权方、日期重叠不得重复签发。
- 已**过期或已撤销**的许可不占冲突位、**不能继续使用**（列表置灰并标注）。

### 费用
- 边际**阶梯费率** + **保底额**取高，得出应收合计。
- 按**结算周期**（月 / 季 / 半年 / 年）自动生成分期收款计划，各期金额之和与应收合计一致。
- 自然周期切分：终止日恰落在周期边界时并入最后一期，**不会产生单日尾期**。例如 `2026-09-16 ~ 2027-09-16` 月结恰为 12 期（季结 4 期、半年结 2 期、年结 1 期）。
- 撤销许可时终止其后未到期的结算期，已到期部分保留。

### 续签 / 撤销
- 续签必须延续同一登记、范围与被授权方，起始日晚于原终止日，前后双向关联（续自 / 续至），同一许可不可重复续签。
- 撤销即时停用许可、终止后续费用期，并写入原因。
- 所有登记、签发、续签、撤销、状态变更均进入「变更流水」。

### 事务与持久化
- 签发是**单一事务**：任何一步校验失败，许可与费用都不会留下半条记录。
- 纹样、登记、许可、费用、流水与序号统一保存在 `localStorage`，关闭重开完整还原；导出文件可在另一处导入完整还原。
- 导入先校验后替换：文件结构、版本、登记 `id` / 登记号 / **指纹三者在文件内均须唯一**、快照与指纹一致、许可/费用无孤儿且金额合计一致；任一不过即整体拒绝，**不覆盖现有数据**。兼容旧版（仅纹样）存档自动升级。
- 「纹样编辑」与「版权台账」两个页签互斥显示，切换页签不丢失各自已填内容与画布状态。

```bash
node test-ledger.js   # 92 项核心业务规则（指纹/唯一性/冲突/费用周期边界/续签/撤销/原子性/导入唯一性）
node test-dom.js      # jsdom 端到端 70 项：页签互斥与状态保留→编辑→登记→签发→冲突→撤销→续签→保存→重开→坏文件拒绝→还原
```
